# Hi, I'm Peter Kure

I'm a cybersecurity professional focused on **security engineering, detection engineering, threat hunting, SIEM telemetry, and AI-assisted SecOps automation**.

My background spans SOC operations, incident response, phishing/BEC analysis, malware triage, vulnerability management, cloud security, and enterprise security/consulting. I’m especially interested in building practical systems that help defenders detect real attacker behavior, reduce investigation friction, and protect users from deception, abuse, and trust-boundary confusion.

This GitHub is where I publish hands-on security engineering projects, detection logic, lab writeups, automation experiments, and technical notes.
